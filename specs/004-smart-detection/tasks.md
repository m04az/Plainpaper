## Implementation Strategy

1. MVP = Quick scan (US2) for immediate reliability, shipped while the model trains.
2. Then the model (US1) behind the fallback (US3).
3. Implementation of well-specified Kotlin tasks (T013, T017–T023) goes to the `implementer`
   subagent; the generator, training, engine integration and tuning stay in the main session.
